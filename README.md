# Algebra Review Lab

Unlimited 20-question Algebra 1 review quizzes covering Chapters 1–4, with instant grading and explanations. Everything runs in the browser — no server or dependencies.

## Hosting with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Pick the branch that holds `index.html` and the **/ (root)** folder, then **Save**.

After a minute the site is live at `https://<owner>.github.io/algebra-review-lab/`.
